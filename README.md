# Шаблон репозитория для лабораторных работ по курсу Технологии программирования 2026 (Kotlin)

## Окружение

1. **JDK 17 или новее**: [скачать тут](https://adoptium.net/);
2. **IntelliJ IDEA Community**: [скачать тут](https://www.jetbrains.com/idea/download/) (поддержка Kotlin в ней уже есть).

Проект собирается через Maven, IDEA подтянет все нужное сама.

## Как начать работу с проектом

1. Сделайте fork к себе на GitHub (инструкция [тут](https://docs.github.com/ru/pull-requests/how-tos/work-with-forks/fork-a-repo)).
2. Склонируйте свой fork: в IDEA тыкаете New → Project from Version Control (транспортный URL вашего форка).
3. После того как IDEA склонировала и проиндексировала ваш проект, можно приступать к работе!

Если у вас уже есть свой репозиторий с прошлыми лабами, форк делать не обязательно: можно скопировать к себе нужные
папки из этого репозитория.

## Структура пакетов

Для каждой лабораторной работы выделен отдельный пакет:

| Пакет       | Лаба   |
|-------------|--------|
| `labs.lab2` | Лаба 2 |
| `labs.lab3` | Лаба 3 |
| `labs.lab4` | Лаба 4 |
| `labs.lab5` | Лаба 5 |
| `labs.lab6` | Лаба 6 |
| `labs.lab7` | Лаба 7 |

Пакеты лежат в `src/main/kotlin/labs`, в каждом уже заведен шаблонный `Main.kt`.

## Как запустить код

Проще всего - нажать зеленый ▶ рядом с функцией `main` в IDEA.

Из терминала (из корня репозитория) программа запускается по имени класса, например программа лабы 2:

```bash
mvn -q compile exec:java -Dexec.mainClass=labs.lab2.MainKt
```

Функция `main` из файла `Main.kt` попадает в класс `MainKt`. Если `main` лежит внутри объекта, укажите его имя,
например `-Dexec.mainClass=labs.lab3.Demo`.

## После выполнения лабораторной

После выполнения лабораторной работы необходимо закоммитить и запушить итоговый код.

Коммиты будут идти в ваш fork, не в оригинальный репозиторий.

При появлении изменений в оригинальном репозитории на GitHub откройте свой fork и нажмите кнопку **Sync fork** после чего выполните `git pull` в терминале.
